Lithium Pro POS v2.3.4 — Secure Realtime Database Rules

هذه النسخة تستخدم نفس بنية allowedUsers الحالية المبنية على Gmail.
قواعد Realtime Database تستطيع تحويل النقاط في البريد إلى فواصل باستخدام String.replace(),
لذلك لم نعد بحاجة إلى نقل المستخدمين إلى UID كي نطبق الصلاحيات الحالية.

طريقة التفعيل:
1) ارفع ملفات المشروع إلى GitHub وانتظر حتى يعمل الموقع.
2) افتح Firebase Console > Realtime Database > Rules.
3) انسخ محتوى الملف firebase/database.rules.json بالكامل وضعه مكان القواعد القديمة.
4) اضغط Publish.
5) اختبر حساب المدير أولاً: إضافة/تعديل/حذف مادة وإنشاء فاتورة.
6) اختبر حساب موظف بصلاحيات محدودة.

- صلاحية invoices تسمح بقراءة الفواتير السابقة فقط؛ إنشاء الفاتورة يعتمد على cashier.
- مسار inventory القديم للقراءة/الترحيل فقط، والكتابة عليه للمدير وحده.

إذا ظهرت Permission denied بعد Publish، لا تحذف البيانات. ارجع مؤقتاً إلى القواعد السابقة وأرسل رسالة الخطأ وصورة شاشة Rules.
